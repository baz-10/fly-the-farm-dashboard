# Organisation Branding and Report Identity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver authoritative organisation branding, branded Mission Packs, and immutable post-completion Mission Records through one durable server-side report artefact architecture.

**Architecture:** Extend the existing Organisation aggregate and store immutable logo versions behind internal file IDs. Capture organisation branding and exact Mission evidence into append-only report artefacts, then render PDFs through a persistent retry-safe job queue and separately deployable report worker. Mission Pack and Mission Record share infrastructure while keeping distinct lifecycle and evidence rules.

**Tech Stack:** React 19, TypeScript, Material UI, Node.js server handlers, PostgreSQL/Supabase RLS and Storage adapters, transactional outbox, Jest/Testing Library, PGlite migration verification, jsPDF server rendering, Vercel deployment.
